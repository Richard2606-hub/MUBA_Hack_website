EVALUATION

Judging Criteria

1. Technical Implementation

30%
  • How well is the project built from a technical standpoint?
  • Does it function as intended with minimal bugs?
  • Is it scalable and efficient?
  • Does it leverage innovative or well-structured solutions?

NOTE: Number of partner integrations will not be taken into account. Our judges will be going through each GitHub; in the event of suspicious commits or multiple contributors are present, you may risk disqualification.

2. Practicality & Impact

30%
  • Is this something users would realistically adopt?
  • Does it bring a meaningful improvement over existing solutions?
  • How well does it address the problem statement?

3. Presentation & Clarity

20%
  • How well did the team communicate their idea and implementation?
  • Is the demo polished and effective in showcasing the project?

4. User Experience (UX) & Design

10%
  • Is the interface intuitive and easy to navigate?
  • Does the project solve a real user pain point effectively?
  • Is the design aesthetically pleasing and accessible?
  • How seamless is the onboarding process?

Basic functions like wallet connecting, transaction confirmation/failure displays, web & mobile compatibility will all be taken into account.

5. Originality

10%
  • Is this a project that has never been seen before?
  • Does it solve current existing problems or is it more of an additional feature towards existing solutions?
