⚡ Gonka Network Challenge

AI for Society

This challenge focuses on real-world applications of AI in the public domain. Participants are encouraged to use the Gonka Network via gonkarouter.io to build tools with genuine value for everyday users.

explore 1. Challenge Directions & Inspiration

The challenge is open-ended — the following directions are provided as inspiration, not constraints:

verified_user AI Fact Checker (Preferred)

A decentralized "Truth Engine" using multi-model AI inference to cross-verify news, social media claims, or digital media in real-time, outputting an on-chain Truth Score (0–100%) and traceable reasoning trail.

translate Multilingual Public Assistant

A censorship-free AI access layer covering education, medical consultation, and legal literacy for non-English-speaking communities worldwide.

accessibility_new AI Accessibility Tools

AI-powered assistive tools designed for users with visual, hearing, or cognitive impairments.

menu_book Open Knowledge Engine

A decentralized Q&A or knowledge retrieval system built on Gonka decentralized inference.

settings_input_component 2. Technical Requirements

  • ⚡ Mandatory: All AI reasoning & verification logic MUST run on Gonka Network via gonkarouter.io.
  • 🔄 Multi-Model Consensus: Encouraged to use at least two models (e.g. MiniMax & Kimi) to cross-verify claims and ensure neutrality.
  • 🎁 Free Access: All participants receive unlimited free token credits during the hackathon for development.

checklist Core Functionality

Claim Extraction: Input URL, tweet, or text snippet.
Decentralized Verification: Analyze via Gonka models vs live data.
Truth Score & Reasoning: Output 0–100% score + reasoning trace.
Transparency UI: Display Gonka Request IDs for each inference.

tips_and_updates 3. Developer Best Practices

  • The "Neutrality" Prompt: Instruct models to be objective and cite specific evidence for conclusions.
  • Cross-Model Comparison: If two models disagree, building a robust "Consensus Logic" is a major plus!
  • On-Chain Proof: Always display the Gonka Request ID to prove results weren't generated by a centralized server.

fact_check 5. Submission Criteria

  • link Live Demo URL: Working web app for live verification
  • code GitHub Repo: Clean code with Gonka Router documentation
  • videocam Video Pitch: 2-minute video showing live verification in action
